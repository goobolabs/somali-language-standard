# Xarafka weyn

Xeerarka isticmaalka **xarafka weyn** (*capital letters*) ee qoraalka Af
Soomaaliga. *Habka Qoraalka* (1977) ma qeexin mawduucan; qaybtan waxay
soo koobaysaa caddaynta laga heli karo [`00-sources.md`](00-sources.md).

## Hordhac

Qoraalka Af Soomaaliga wuxuu raacaa farta Laatiinka tan iyo 1972–1973.
Xeerarka xarafka weyn weli si rasmi ah uguma jiraan hal buug dhammaystiran
— waxay ku kala firfircoon yihiin buugaagta dugsiga iyo dhaqanka qoraalka
ee daabacaadda. Ilaha hadda la haysto waxay isku raacsan yihiin in
xarafka weyn loo isticmaalo sida badanaa Ingiriisida, iyadoo tusaalooyin
gaar ah la tixgeliyo.

## Bilowga weedha

**Weertu waxay ka bilaabantaa xaraf weyn** — weedh kasta oo madax-bannaan
waxay ku bilaabataa xaraf weyn marka ay bilowdo jumladda ama qayb cusub
oo qoraal ah.

Tusaalo:

```
Cali wuu yimid.
Maanta waa Sabti.
```

## Magacyada gaarka ah

Magacyada gaarka ah (*proper nouns*) — dad, meelo, dalal, magaalooyin,
iyo magacyo kale oo gaar ah — waxaa caadi ah in xaraf weyn lagu qoro
bilowgooda.

| Nooc | Tusaale |
| --- | --- |
| Dal / magaalo | Soomaaliya, Muqdisho, Hargeysa |
| Qof | Cali, Faadumo, Sayid Maxamed |
| Meel gaar ah | Afgooye, Garoowe |

## Maalmaha toddobaadka iyo bilaha

Maalmaha toddobaadka iyo bilaha sannadka waxaa caadi ah in xaraf weyn
lagu qoro marka magac ahaan loo isticmaalayo:

| Maalmaha | Bilaha (tusaalo) |
| --- | --- |
| Isniin, Talaado, Arbaco, Khamiis, Jimce, Sabti, Axad | Jannaayo, Abriil, Maajo, … |

Tusaale: *Maanta waa Sabti.* — *Waxaan ku dhalanay Abriil.*

## Qowmiyadaha iyo luqadaha

Erayada tilmaamaya qowmiyad ama luqad waxaa caadi ah in xaraf weyn
lagu qoro marka magac ahaan loo isticmaalayo:

| Nooc | Tusaale |
| --- | --- |
| Qowmiyad | Soomaali |
| Luqad | af Soomaali |

Tusaale: *Waxaan ahay Soomaali.* — *Waxaan bartaa af Soomaali.*

## Xilliyada sannadka

Magacyada xilliyada sannadka (sida *jiilaal*, *gu*, *dayr*, *xagaa*) waxaa
badanaa loo qoraa xaraf weyn marka magac ahaan loo isticmaalayo, laakiin
mararka qaarkood xaraf yar ayaa sidoo kale la isticmaalaa marka macnaha
guud ee xilliga la tilmaamayo:

```
Jiilaal waa xilli qalalan.
Waxaan ku noolahay jiilaal kulul.
```

## Jihada afarta

Afarta jiho ee waaweyn (*koonfur*, *waqooyi*, *bariga*, *galbeed*) waxaa
sidoo kale caadi ah in xaraf weyn lagu qoro marka magac ahaan loo isticmaalayo,
iyadoo la raacayo isla qaabka xilliyada:

```
Koonfur waa jihada hoose.
Waxaan u safray koonfur.
```

## Xusuusin

- Xeerarkan kuma jiraan *Habka Qoraalka* (1977); waxay ku tiirsan yihiin
  dhaqanka qoraalka iyo ilaha lagu tilmaamay [`00-sources.md`](00-sources.md).
- Buugga Wasaaradda Warfaafinta ee 1974 wuxuu diiradda saarayaa taariikhda
  qorista afka iyo ololaha akhriska — **ma uu qeexin xeerarka xarafka weyn**
  markii la baadhay (2026-07-18).
- Marka il Somali ah oo rasmiga ah loo helo, qaybtan waa in dib loo eegaa.
