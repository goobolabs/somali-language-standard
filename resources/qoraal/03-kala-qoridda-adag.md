# Meelaha ay Adag Tahay Kala Qoridda

## Hordhac

Afkeennu wuxuu leeyahay meelo aanay hawl yareyn koobidda fidsanaantu. Meelahaas waxa ka mid ah marka falka *ah* uu ku lifaaqmo tilmaamayaasha qaarkood.

Hordhaca hadalka iyo qoraalka waxa laga helayaa [`01-hadal-iyo-qoraal.md`](01-hadal-iyo-qoraal.md). Koobnaanta iyo fidsanaanta waxa laga helayaa [`02-eray-kooban-hadalka.md`](02-eray-kooban-hadalka.md).

## Falka *ah* iyo tilmaame

Falka *ah* marka loo eego magacuyaalka dad ee aanu raacin waa sidan:

```
waxa aynu nahay barayaal
waxa aad tahay bare
waxa aydin tihiin barayaal
waxa uu yahay bare
waxa ay tahay bare
waxa ay yihiin barayaal
```

Baradigmaha dhan ee falka *ah* waxa laga helayaa [`naxwe/08-hogatuska-baradigmaha-falalka.md`](../naxwe/08-hogatuska-baradigmaha-falalka.md).

Haddii aan tilmaame ka horraysiiyo falka *ah*, neelaha qaarkood waxay dhacaan koobnaan salka ku haysa isbeddel codeed. Taas oo sharci ahaan aan loo kala qori karin erayga keenay isbeddelkaas.

## Tusaalooyin — *waa* + tilmaame

**Koobnaan (hadalka)**

```
waa madoobahay
waa nadawnahay
waa nadawyahay
waa ladanahay
waa ladantahay
waa ladanyahay
```

**Fidsanaan (qoraalka)**

```
waa nadaw ahay
waa nadaw nahay
waa nadaw tahay
waa nadaw tihiin
waa nadaw yahay
waa nadaw yihiin

waa ladan ahay
waa ladan nahay
waa ladan tahay
waa ladan tihiin
waa ladan yahay
waa ladan yihiin
```

## Meelaha ay hawl yar tahay kala qoridda

Meelaha ay hawl yar tahay kala qoridda, maxaa yeelay isbeddel codeed ma dhicin:

```
Madaw nahay     →  waa nadaw nahay
ladan nahay     →  waa ladan nahay
```

## Meelaha aanay hawl yareyn kala qoridda

Meelaha aanay hawl yareyn kala qoridda, waxa dhacay isbeddel codeed. Kala qoridda waxay u qaybsami kartaa laba siyood:

**I — nid waafaqsan dhihidda**

```
madoobahay  →  waa nadaw ahay
ladanahay   →  waa ladan ahay
```

**II — nid waafaqsan naxwaha salka ah**

```
nadaw dahay   →  waa nadaw tahay
nadaw tihiin  →  waa nadaw tihiin
ladan ahay    →  waa ladan ahay
ladan tahay   →  waa ladan tahay
```

## Isku hor imaadka sharciyada

Marka hadalka ay isku dhafmaan tilmaame iyo falka *ah*, haddii sharciga qoridda oo ah lagama eray oo aan isku qayb hadal ahayn lama isku qoro, sidee baa loo kala qori karaa labada eray ee kala qoriddooda sharciga isbeddel codeed burinayo?

Waxa halkaas ka muuqata in ay laba sharci isku hor yimaadaan:

1. Sharciga qoraal ee salka ku haya koobnaanta iyo fidsanaanta
2. Sharciga is dhalan rogista ee salka ku haya isbeddelka codeed

Sharciga dambe waa isku qoridda erayyadan sanceysan.

Labada sharci ee kala qoridda waxa laga helayaa [`01-hadal-iyo-qoraal.md`](01-hadal-iyo-qoraal.md).

## Is dhalan rogista codka

Haddii eray shaqalka dheer ee *n* uu ugu danbeeyo oo dabadeedna uu ku lifaaqmo lifaaq codkiisu ugu horreeyaa */t/ yahay, codka lifaaqa ugu horreeya */t/ wuxuu isu beddelaa */d/*. Isbeddelka sidaas ah ee ku lug leh dhismaha codadka waxaa lagu magacaabaa is dhalan rogista codeed.

Tusaale:

```
caw + ta   →  cawda
caw + taa  →  cawdaa
caw + tay  →  cawday

madaw + tahay   →  madawdahay
madaw + tihiin  →  madawdihiin
```

Markaas sharciga sidaas ah ee *madawdahay* iyo *madawdihiin* sax sugan ka dhigaya iyo sharciga u degsan hadalka iyo qoraalka ee ku saabsan koobnaanta iyo fidsanaanta ayaa tusaalayaasha iskaga hor imanaya.

Isbeddellada *t* → *d* ee qodobka iyo nadooca waxa laga helayaa [`naxwe/03-sarfaha-tifaftireyaasha.md`](../naxwe/03-sarfaha-tifaftireyaasha.md) iyo [`sarfe/04-isbeddelka-codka.md`](../sarfe/04-isbeddelka-codka.md).

## Go'aanka qoraalka

Waxa inoo cad in ay go'aan u baahan tahay in nid ahaan la dhaafo marka laga la habaynayo qoraalka. Waxa la talinayaa in la dhawro labada sharci ee ku saabsan koobnaanta iyo fidsanaanta ee ah in la kala qoro labada eray ee kala qayb hadal ah:

```
waa nadaw ahay
waa nadaw nahay
waa nadaw tahay
waa nadaw tihiin
waa nadaw yahay
waa nadaw yihiin

waa ladan ahay
waa ladan nahay
waa ladan tahay
waa ladan tihiin
waa ladan yahay
waa ladan yihiin
```

Markaas waa in tilmaame iyo falka *ah* sidan loo qoro:

```
waa ladan ahay
waa ladan nahay
waa ladan tahay
waa ladan tihiin
waa ladan yahay
waa ladan yihiin
```
