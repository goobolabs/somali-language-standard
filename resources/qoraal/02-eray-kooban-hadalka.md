# Ereyada Afkeenna Koobma Marka Hadalka

## Hordhac

Qoraalka waxa uu leeyahay hab fidsan oo eray kasta ay lagama maarmaan tahay in uu gooni u qormo, haddii aan looga jeedin in uu yahay hadal la qoray sida sheekaysiga. Waxa qoraalka laga dhuuxi karaa in aanay ku dambayn eray kale oo uu gooni u qoran yahay, marka se la isku duubo erayyo ay tahay sumad hadalka u gaar ah sida weedhaha ku jira labada kolmo.

Hordhaca hadalka iyo qoraalka waxa laga helayaa [`01-hadal-iyo-qoraal.md`](01-hadal-iyo-qoraal.md). Koobnaanta iyo fidsanaanta waxa kaloo laga helayaa [`naxwe/14-naxwaha-cusub.md`](../naxwe/14-naxwaha-cusub.md) §4.2.

## Fidsanaanta erayga *bay*

Eray marka uu kooban yahay wuxuu yeelan karaa fidsanaan dhawr siyood ah. Erayga *bay* fidsanaantiisu waxay noqon kartaa:

```
bay = baa ii
bay = baa ay
bay = baa ay ii
bay = baa lay ii
bay = baa i
```

## Koobnaan iyo fidsanaan — tusaalooyin naxweed

### 1. Geed + fal

**Koobnaan**

```
Geedaan beeray
Geedaannu beernay
Geedaynu beernay
Geedaad beertay
Geedaydin beerteen
Geeduu beeray
Geeday beertay
Geeday beereen
```

**Fidsanaan**

```
Geed aan beeray
Geed aannu beernay
Geed aynu beernay
Geed aad beertay
Geed aydin beerteen
Geed uu beeray
Geed ay beertay
Geed ay beereen
```

## Gabagabo

Meelaha afkeenna koobma marka hadalka ee ay tahay in la kala fidiyo waa kuwa kor ku qoran iyo kuwa la mid ah. Qoraalku wuxuu u baahan yahay in eray kasta gooni loo qoro si loo fududeeyo barashada naxwaha iyo kala soocidda qaybaha hadalka.

Meelaha ay adag tahay kala qoridda waxa laga helayaa [`03-kala-qoridda-adag.md`](03-kala-qoridda-adag.md). Meelaha aanay habboonayn kala qoridda waxa laga helayaa [`04-kala-qoridda-lama-qasban.md`](04-kala-qoridda-lama-qasban.md).
