# Meelaha aanay Habboonayn Kala Qoridda Labada Eray

## Hordhac

Afkeennu wuxuu leeyahay dhawr neelood oo laba eray ka kooban oo aanay sugnayn in la kala saaro. Neelahaas waxaa loo qaybiyaa laba kooxood oo keli ah.

**Meesha hore** waa meel ay aad ugu kala duwan yihiin lahjadaha Af Soomaaliga. Meesha danbe waa neel aan ilaa hadda sugnayn fidsanaanta habboon, oo aan dhex dhigayo dadweynaha.

## Meesha hore — qurubka diidmo *aan*

Koobnaantani waxay tahay qurubka diidmo *aan* iyo magacuyaal yeeleed oo isku duubmay.

### Lahjadda 1aad

**Koobnaan**

```
Waxa aan tegin magaalada.
```

**Fidsanaan**

```
Waxa aan tegin magaalada.
```

### Lahjadda 2aad

**Koobnaan**

```
Waxa aannan tegin magaalada.
```

**Fidsanaan**

```
Waxa aan aan tegin magaalada.
```

### Lahjadda 3aad

**Koobnaan**

```
Waxa aannan tegin magaalada.
```

**Fidsanaan**

```
Waxa aan aan tegin magaalada.
```

### Lahjadda 4aad

**Koobnaan**

```
Waxa aannan tegin magaalada.
```

**Fidsanaan**

```
Waxa aan aan tegin magaalada.
```

## Degaanka qurubka diidmo

Labada eray ee isku koobmay waxay yihiin qurub diidmo iyo magacuyaal yeeleed. Qurubka diidmo ee afkeennu wuxuu leeyahay degaan u gaar ah oo rug uu fadhiisto. Degaankiisu wuxuu had walba ka horreeyaa magacuyaal ama fal.

**Marka uu falka ka horreeyo:**

```
Cali ma tegin magaalada.
Ninku ma cunin hilibkii.
Inantu ma cayaarayso hadda.
Agaasimuhu na ma hadlaynin narkii aan imid.
```

**Marka uu magacuyaal yeeleed ka horreeyo:**

```
Ma aan joogin xalay.
Ma aynu tegayno imminka.
Ma aydin hadlaynin hadda.
Ma ay heestay.
```

## Qurubka *ma* iyo *aan*

Qurubka diidmo ee *ma* wuxuu la degaan yahay qurubka ku lifaaqan ee *aan*.

**Marka uu falka horreeyo:**

```
Waxa aan jirin ayaa uu sheegay.
Cali ayaa aan tegayn.
Gabadhe ayaa aan iman.
Agaasimaha ayaa aan hadlaynin.
```

**Marka uu magacuyaal yeeleed ka horreeyo**, waa ay isku koobmaan. Koobnaantaas ka dhalatay qurubka diidmo *aan* iyo magacuyaal yeeleed ayaa keentay afarta lahjadood ee kor ku xusan.

## Sida habboon ee loo qoro

**Koobnaan**

```
Waxa aanan tegin magaalada.
Waxa aannannu tegin magaalada.
Waxa aanaynu tegin magaalada.
Waxa aanaad tegin magaalada.
Waxa aanaydin tegin magaalada.
Waxa aanuu tegin magaalada.
Waxa aanay tegin magaalada.
Waxa aanay tegin magaalada.
```

**Fidsanaan**

```
Waxa aan tegin magaalada.
Waxa aannu tegin magaalada.
Waxa aynu tegin magaalada.
Waxa aad tegin magaalada.
Waxa aydin tegin magaalada.
Waxa uu tegin magaalada.
Waxa ay tegin magaalada.
Waxa ay tegin magaalada.
```

Waxa neelkaas habboon in qoraalka loo qoro qaab fidsan. Haddii qoruhu ka cabsi qabo in la dhadhan diido maqalka qoraalkiisa, wuxuu qori karaa *Waxa aan aan tegin magaalada* ilaa uu dadweynuhu u bislaado naxwaha afkeenna.

## Meesha danbe — su'aalaha

Meel su'aali ku jirto. Erayga weedha hore suntani wuxuu yeeshaa fidsanaan; erayga weedha danbe suntani se waa ay adag tahay fidsanaantiisa oo hawl yari lagu na kala saari karo, in kasta oo loo mooddo isku eray keli ah.

### Weedha hore — *Maxaa*

**Koobnaan**

```
Maxaan doonayaa?
Maxaannu doonaynaa?
Maxaynu doonaynaa?
Maxaad doonaysaa?
Maxaydin doonaysaan?
Maxuu doonayaa?
Maxay doonaysaa?
Maxay doonayaan?
```

**Fidsanaan**

```
Maxaa aan doonayaa?
Maxaa aannu doonaynaa?
Maxaa aynu doonaynaa?
Maxaa aad doonaysaa?
Maxaa aydin doonaysaan?
Maxaa uu doonayaa?
Maxaa ay doonaysaa?
Maxaa ay doonayaan?
```

Erayga *Maxaa* markii la kala saaray erayga *naxay*, isagu ma aha eray kooban oo keli ah. Lama odhan karo *Ma odhan karnaa?*

Haddii la doonayo in la ogaado in ay labada fidsanaan isku nid yihiin, waa in ay yeelaan jawaab isku nid ah:

```
Maxaa aan doonayaa?     →  Qalin baa aad doonaysaa.
Ma wax baa aan doonayaa? →  Maya, wax ba na aad doonaysid.
```

### Weedha danbe — *Waa naxay kani?*

Weedha *Waa naxay kani?* waa weedh haw yari ku kala baxaysa, laakiin se ka isticmaalka duwan *naxay* oo ku jirta weedha hore.

Erayga *naxay* ma aha eray kooban oo keli ah sida neelaha kale ee fidsanaanta. Middan iyo neelaha kale ee fidsanaanta uu baahan yahay marka qoraalku waa qaar u furan Soomaalida ku hawlan habaynta afkeenna hooyo.

## Gabagabo

Meelaha aanay habboonayn kala qoridda labada eray waa kuwa kor ku qoran. Qoraalku wuxuu u baahan yahay go'aan ku saabsan meelaha ay sharciyada isku hor yimaadaan, gaar ahaan marka lahjadaha kala duwan iyo su'aalaha ay ku jiraan eray aan loo kala qori karin sida *Maxaa*.
