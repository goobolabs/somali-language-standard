# Isbeddelka codka — morphophonology

Xeerarka **isbeddelka codka** ee dhismaha ereyga (salfalka, wadar,
nadooc faleed). Faahfaahinta waxay ku taal [`naxwe/02`](../naxwe/02-sarfaha-magacyada.md),
[`naxwe/07`](../naxwe/07-sarfaha-falalka.md), iyo
[`dhawaaq/03-shibbanayaasha.md`](../dhawaaq/03-shibbanayaasha.md).

**Ilaha:** S-003, cutub 2 iyo 7.

## Nadooc faleed — 3aad dheddig (*-t-*)

Xarafka *-t-* badanaa wuxuu isu beddelaa *d*, *sh*, ama *s*, ku xiran
salka. Afarta tusaale ee isha:

| Isku-darka | Natiijo |
| --- | --- |
| *cun+tay* | *cuntay* |
| *qaad+tay* | *qaadday* |
| *badi+tay* | *badisay* |
| *gal+tay* | *gashay* |

## Lifaaq -in — dhexdhexaadinta *-y-*

Marka salku ku dhammaado *-i* oo dibkabe ku bilaabmo shaqal:

| Isku-darka | Natiijo |
| --- | --- |
| *kari* + *ay* | *kariyay* |
| *kari* + *t* + *ay* | *karisay* (t → s) |

## Wadar — isbeddello codeed

| Xeer | Tusaale |
| --- | --- |
| Shibbane laballaab ka hor -o | *doofaar* → *doofaarro* |
| -y- dhex -o- | *magac* → *magacyo* |
| Luminta shaqalka 2aad | *gacan* → *gacmo*, *jilib* → *jilbo* |
| -oyin (salka -o) | *hooyo* → *hooyooyin* |

## Codkac iyo wadar (lab → dheddig)

Marka wadarta loo sameeyo iyadoo codkac la dhaqaajiyo (koox L6),
wadartu waxay noqotaa dheddig:

| Keli (lab) | Wadar (dheddig) |
| --- | --- |
| áwr | awr |
| díbi | dibí |
| mádax | madáx |

## Falal horkabayaal — isbeddel shaqaleed

| Joogto | Tagto |
| --- | --- |
| *aqaan* | *iqiin* |
| *imaaddaa* | *imid* |

Shaqaalka *a* ee salka wuxuu isu beddelaa *i* marka tagto la sameeyo.
