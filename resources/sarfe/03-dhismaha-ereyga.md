# Dhismaha ereyga — lifaaqyo iyo farcamo

Shaxda tixraaca ee **lifaaqyada falka**, **falkaaliyeyaasha**, iyo **magacyada
ka soo farcama falal**. Faahfaahinta barashada waxay ku taal
[`naxwe/07-sarfaha-falalka.md`](../naxwe/07-sarfaha-falalka.md) (§7.2–7.3).

**Ilaha:** S-003, cutub 7.

## Lifaaqyada falka ee ugu muhiimsan

| Lifaaq | Micnaha | Tusaale |
| --- | --- | --- |
| -in | sababeed (causative) | *kar* → *karin* |
| -an | falasho (middle/reflexive) | *dhaq* → *dhaqan* |
| -am | yeele dahsoon | *fur* → *furmay* (albaab) |
| -siin | yeelsiin | *cab* → *cabsiin* |
| -ayn/-eyn | ka yimid magac/sifo | *qado* → *qadayn* |
| -aan | ka yimid fal sifo | *dheer* → *dheeraan* |
| -oob | noqosho (magac) | *biyo* → *biyoob* |
| -ood | dareemid (magac) | *dhaxan* → *dhaxmood* |

## -in: isrogrogga I → II

| Amar (I) | Amar (II) | Masdar |
| --- | --- | --- |
| mar | mari | marin |
| gal | geli | gelin |
| deg | deji | dejin |
| daal | daali | daalin |
| dhal | dhali | dhalin |

## -an: qaababka muuqda

| Qaab | Adeegsiga |
| --- | --- |
| -an | masdar + falkaaliye + joogto socota |
| -o | amar keli |
| -at | qaababka kale (*baratay*) |

## Magacyada ka soo farcama falal

| Nooc | Dibkabe | Cayn | Tusaale |
| --- | --- | --- | --- |
| Magac saleed | @ (eber) | lab | *qosol*, *karis* |
| Magac faleed | -id / -in / -sho / -aan | dheddig | *qoslid*, *karin*, *barasho* |
| Magac fale | -e / -ye | lab | *qosle*, *kariye*, *barte* |

### Magac faleed iyo isrogrog

| Isrogrog | Dibkabe | Tusaale |
| --- | --- | --- |
| I | -id | *qoslid* |
| II | -in | *karin*, *sameyn* |
| III | -sho | *barasho* |
| Fal sifo | -aan | *yaraan* |

## Fal gudbe vs magudbe

| Nooc | Tilmaam | Tusaale |
| --- | --- | --- |
| Gudbe | yeele + layeele | *Cali waraaq buu qoray* |
| Magudbe | yeele keli | *Cali wuu seexday* |

Fal gudbe wuxuu noqon karaa magudbe iyadoo la beddelayo qaabka
weerta; fal magudbe wuxuu noqon karaa gudbe lifaaq *-in*.
