# Naxwe — Somali grammar reference

A Somali-language grammar reference covering the full scope of Somali
descriptive grammar. This is a **reference and source-of-truth document**,
intended for use in AI, NLP, machine translation, and linguistic analysis —
not as a learning textbook (exercises are excluded).

## Conventions

- All prose is in Somali; grammatical terms follow the Somali tradition (*magac*,
  *fal*, *weer*, …), with an English gloss on first use.
- Ungrammatical examples are marked with an asterisk (`*`), per standard linguistic
  convention.
- Chapter numbering follows a three-part structure:
  - **00–01** — sound & word (phonology, lexicology)
  - **02–08** — word classes (noun, determiner, pronoun, numeral, preposition, verb)
  - **09–12** — sentence structure (simple, NP, complex, sentence types)
- `ereyfur.tsv` is a flat three-column glossary (no definitions — terms are explained
  in context within the chapters above).
