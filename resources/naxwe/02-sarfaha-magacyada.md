# 2. Sarfaha magacyada

## 2.1 Magacyada

Ereyada ay luqadi leedahay isku wada mid ma aha: waxaa loo kala
qaybin karaa dirar (word classes) kala duwan. Dirta hore ee la
qeexayo waa **magaca** (noun). Tusaalayaal (ereyada magacyada ah):

1) *Nin* baa *beerta* ka yimid.
2) *Muqdisho* way sii ballaaratay.
3) *Geedku* waa cagaaran yahay.
4) *Wiilwaal* wuxuu ahaa *dagaalyahan*.
5) *Xiinfaniin* waa *faras* caan ah.
6) *Magaalada* ayaan aadayaa.
7) *Soomaaliya* waa *dal* ballaaran.

Si loo ogaado dirta uu erey ka tirsan yahay waxaa la tixgeliyaa laba
shay: **micnihiisa** iyo **qaabkiisa**.

### Micnaha magaca

Magacyadu waa ereyo micnahoodu ka kooban yahay fikradaha loo baahan
yahay in lagu aqoonsado waxyaabo is leh: dadka, xayawaanka,
ashyaa'da, meelaha, waqtiga, dhacdooyinka. Marka hadluhu ku
dhawaaqo *nin*, wuxuu dhegeystaha u tilmaamayaa dir leh dabeecadahan:
noole, binii-aadan, lab, qaangaar. Macnaha uu magac leeyahay wuxuu
xambaarsan yahay astaamo iyo dabeecado gaar ah, kuwaas oo shay ka
dhiga mid ka mid ah dir go'an.

**Magac gaar** (proper noun) wuxuu tilmaamaa qof ama wax gaar ah, si
uu uga soocmo kuwa kale ee la nooca ah: *Muqdisho* (magaalooyinka),
*Wiilwaal* (nimanka), *Xiinfaniin* (fardaha), *Soomaaliya* (dalalka).

**Magac guud** (common noun) ma tilmaamo qof ama meel gaar ah, ee
wuxuu tilmaamaa inta shay ee leh dabeecado isku mid ah: *nin*,
*beer*, *geed*, *faras*, *magaalo*, *dal*.

Magacyada guud waxay iyaguna u kala baxaan laba koox:

- **magacyo caadyaal ah** (concrete) — wax nool ama la taaban karo,
  la arki karo: *nin*, *kalluun*, *libaax*, *guri*, *dhagax*, *buug*;
- **magacyo cillanaad ah** (abstract) — dareen, ra'yi, fikrad:
  *jacayl*, *nacayb*, *sharaf*, *caddaalad*.

### Qaabka magaca

Magaca waxaa qaab ahaan lagu aqoonsan karaa laba siyood:

a) inta badan magacu wuxuu yeelan karaa qaabab kala duwan markuu
tilmaamayo hal wax (**keli**, singular) iyo markuu tilmaamayo hal wax
ka badan (**wadar**, plural): *geed*/*geedo*, *af*/*afaf*;

b) magaca waxaa raaci kara **qodob** (article/determiner) ku dhega
dhammaadkiisa (*ninka*, *naagta*, *buugga*, *irridda*, *qolka*,
*hasha*, *diiqa*, *qodaxda*), ama **tilmaame** (demonstrative) sida
-kan/-tan, -kaas/-taas (*buuggaas*, *ninkan*, *sartan*, *naagtaas*).

Gunaanad: haddii erey uu yeelan karo keli iyo wadar, isla
markaantaana lagu lifaaqi karo qodob ama tilmaame, ereygaasi waa
**magac**.

## 2.2 Caynta magaca

Bal isbarbardhig labadan taxane:

| A (wax nool) | B (wax aan noolayn) |
| --- | --- |
| aabbe | guri |
| hooyo | bad |
| gabar | qalin |
| wiil | derbi |
| maroodi | bir |
| deero | muraayad |

Magacyada noolaha (taxanaha A) waxaa lagu kala saari karaa **lab**
(masculine) iyo **dheddig** (feminine) iyadoo la eegayo jinsiga:
caynta dabiiciga ah ayaa ku xiran caynta naxweed.

Magacyada aan noolayn (taxanaha B) iyaguna cayn naxweed way
leeyihiin, laakiin jinsi laguma kala saari karo. Cayntooda waxaa
laga ogaadaa **waafaqidda curiyeyaasha kale ee weerta**:

8) *Deeradu biyo bay cabtay.*
9) *Maroodigu biyo buu cabbay.*

Magacyada *deero* iyo *maroodi* waxaa raacsan qodobbo kala duwan
(*-du* iyo *-gu*), magacuyaallo kala duwan (*bay* iyo *buu*) iyo
dhammaad faleedyo kala duwan (*cabtay* iyo *cabbay*). Isweydaarintu
waxay dhalisaa weero qalad ah:

10) \**Deeradu biyo buu cabbay.*
11) \**Maroodigu biyo bay cabtay.*

Sidaas darteed magac kasta waxaa loo qaybin karaa lab ama dheddig
marka laga eego curiyeyaasha la halmaala:

- **Lab**: qodobbada *-ku/-gu*, magacuyaalka *buu* (uu), falka oo ku
  dhammaada *yahay* — *Qalinku wuu dheer yahay* (sida *Ninku wuu
  dheer yahay*).
- **Dheddig**: qodobbada *-tu/-du*, magacuyaalka *bay* (ay), falka oo
  ku dhammaada *tahay* — *Birtu way gaaban tahay* (sida *Naagtu way
  gaaban tahay*).

Soo koobid: caynta magacu waa lab ama dheddig. Magacyada noolaha
cayntooda naxweed waxay ku xiran tahay jinsigooda; kuwa aan noolayn
cayntooda waxaa laga ogaadaa sida uu magacu ula waafaqo curiyeyaasha
weerta ku jira.

### 2.2.1 Codkaca iyo caynta

Caynta magaca miyaa la garan karaa iyadoo aan la raacin
tifaftireyaal sida qodobbada? Run ahaantii, caynta magaca waxaa asal
ahaan lagu kala saari karaa **codkaca**; in yar ayaa cayntooda laga
fahmi karaa dhammaadka magaca.

- Magacyada **labka ah**: codkacu wuxuu saaran yahay shaqalka ugu
  dambeeya **kan ka horreeya**.
- Magacyada **dheddigga ah**: codkacu wuxuu saaran yahay shaqalka
  **ugu dambeeya**.

Magacyo mataanays ah oo codkaca oo keliya lagu kala saaro:

| Lab | Dheddig |
| --- | --- |
| ínan(ka) | inán(ta) |
| céesaan(ka) | ceesaán(ta) |
| dálab(ka) | daláb(ta) |
| shílin(ka) | shilín(ta) |
| íllin(ka) | illín(ta) |
| áqoon(ka) | aqoón(ta) |
| néef(ka) | neéf(ta) |
| fóol(ka) | foól(sha) |
| kéli(ga) | kelí(da) |
| bálli(ga) | ballí(da) |

Magacyada hal-alanleyaasha ah (monosyllabic) waxaa lagu kala soocaa
shaqalka oo laba siyood loogu dhawaaqo — **culus** markuu ereygu lab
yahay, **fudud** markuu dheddig yahay:

| Lab | Dheddig |
| --- | --- |
| ur(ka) | ur(ta) |
| gar(ka) | gar(ta) |
| dul(ka) | dul(sha) |
| tuur(ka) | tuur(ta) |
| qoor(ka) | qoor(ta) |

Ugu dambayn, magacyada qaarkood caynta waxaa laga garan karaa xarafka
ay ku dhammaadaan: kuwa ku dhammaada **-e waa lab**, kuwa ku
dhammaada **-o waa dheddig**:

| Lab (-e) | Dheddig (-o) |
| --- | --- |
| bare | ardo |
| tuke | cusbo |
| qore | maro |
| wade | talo |
| waraabe | dawo |
| fure | golo |
| curre | gato |

## 2.3 Tirada

Magacu wuxuu leeyahay qaab gaar ah markuu tilmaamayo hal qof, hal
xayawaan ama hal shay (**qaab keli**), iyo qaab kale markuu
tilmaamayo hal wax ka badan (**qaab wadar**):

| Keli | Wadar |
| --- | --- |
| buug | buugag |
| guri | guryo |
| nirig | nirgo |
| tuke | tukayaal |

Marka magac wadar laga dhigayo, qayb ka mid ah ayaa isbeddesha:
qaybta dambe ee isbeddesha waxaa lagu magacaabaa **dhammaad**
(ending), qaybta aan isbeddelinna **sal** (stem/root).

### Magacyada aan wadar yeelan

Magac kastaa wadar ma yeesho:

- **Magacyada aan tirsamin** (mass nouns) — shay aan la tirin karin:
  *sonkor*, *biyo*, *subag*, *caano*, *ciid*, *shaah*, *saliid*,
  *oon*. Macquul ma aha \**hal sonkor*, \**laba sonkor*; sidaas
  darteed qaab wadareed ma yeeshaan (*Sonkor badan baan rabaa*).
- **Magacyada ururka ah** (collective nouns) — waxay tilmaamaan wax
  badan, laakiin loo arko hal ahaan: *rag*, *dumar*, *dad*, *geel*,
  *lo'*, *ari*, *ido*, *carruur* (*Rag badan baa yimid*).
- **Magacyada cillanaadka ah** intooda badan wadar looma adeegsado:
  *ceeb*, *run*, *ciil*, *dadnimo*, *doqonnimo*, *murugo*, *jacayl*.

Haddaba magacyada **tirsama** oo keliya ayaa wadar noqon kara.
Qaybaha iyo qayb-hoosaadyada magacyada:

```
magac
├── gaar (Cali)
└── guud
    ├── cillanaad (run)
    └── caadyaal
        ├── ma-tirsame (sonkor)
        └── tirsame
            ├── urur (dad)
            └── aan urur ahayn (buug)
```

### 2.3.1 Dibkabayaasha wadarta sameeya

#### A) Magacyada labka ah

**I. Hal-alanleyaasha:** waxay ku wadaroobaan iyagoo laballaabaya
shibbanaha ugu dambeeya, kuna daraya shaqalka *-a*. Cayntoodu isma
beddesho (mar kastaba waa lab):

| Keli | Wadar |
| --- | --- |
| buug(ga) | buugag(ga) |
| koob(ka) | koobab(ka) |
| af(ka) | afaf(ka) |
| miis(ka) | miisas(ka) |

**II. Kuwa ka samaysan in ka badan hal alan** waxay wadar noqdaan
iyadoo la adeegsanayo dibkabayaal kala duwan:

**1) Ku-daridda -o** (wadartu waxay noqotaa dheddig). Isbeddel codeed
ayaa inta badan dhaca:

a. Haddii magacu ku dhammaado *b, d, n, l, r* — shibbanaha ugu
dambeeya wuu laballaabmaa:

| Keli | Wadar |
| --- | --- |
| wadaad(ka) | wadaaddo(da) |
| doofaar(ka) | doofaarro(da) |
| sacab(ka) | sacabbo(da) |
| qamuun(ka) | qamuunno(da) |
| shabeel(ka) | shabeello(da) |

b. Haddii magacu ku dhammaado *s, q, c, f, x, i* — waxaa *-o*-da iyo
xarafka uu ereygu ku dhammaado la dhex dhigaa *-y-*:

| Keli | Wadar |
| --- | --- |
| kurus(ka) | kurusyo(da) |
| dariiq(a) | dariiqyo(da) |
| magac(a) | magacyo(da) |
| libaax(a) | libaaxyo(da) |
| waraf(ka) | warafyo(da) |
| dugsi(ga) | dugsiyo(da) |

c. Haddii magacu ku dhammaado *-y* — isbeddel codeed ma dhaco:
*gabay(ga)* → *gabayo(da)*, *kuray(ga)* → *kurayo(da)*, *erey(ga)* →
*ereyo(da)*, *oday(ga)* → *odayo(da)*.

d. Magaca labeed ee ka samaysan laba alan oo leh dhismaha
shibbane+shaqal+shibbane+shaqal+shibbane, aan kuna dhammaanayn
*kh, c, x, q*: wuxuu lumiyaa shaqalka labaad, oo laba-alanle buu sii
ahaadaa. Cayntuna isma beddesho (waa lab):

| Keli | Wadar |
| --- | --- |
| jilib(ka) | jilbo(ha) |
| garab(ka) | garbo(ha) |
| ilig(ga) | ilko(ha) |

**2) Ku-daridda -yaal** magacyada labka ah ee ku dhammaada *-e*
(wadartu waxay noqotaa dheddig):

| Keli | Wadar |
| --- | --- |
| aabbe(ha) | aabbayaal(ta) |
| tuke(ha) | tukayaal(ta) |
| bare(ha) | barayaal(ta) |
| gole(ha) | golayaal(ta) |

**3) Ku-daridda -aan** (magacyo aan badnayn; shaqalka dambe waa
luntaa): *dhagax* → *dhagxaan(ta)*, *ugax* → *ugxaan(ta)*.

**4) Qaabka af-carbeedka** — magacyada asalkoodu ka soo jeedo af
carbeedka: *macallin* → *macallimiin(ta)*, *dersi* → *duruus(ta)*,
*weli* → *awliyo(da)*.

**5) Durkidda codkaca oo keliya** — dibkabe la'aan, codkaca ayaa
gadaal u dhaqaaqa. Codkac ku beegan shaqalka ugu dambeeyaa waa
dabeecadda magacyada dheddigga ah, sidaas darteed wadartani waa
dheddig:

| Keli | Wadar |
| --- | --- |
| áwr(ka) | awr(ta) |
| Cárab(ka) | Caráb(ta) |
| díbi(ga) | dibí(da) |
| mádax(a) | madáx(da) |
| órgi(ga) | orgí(da) |

#### B) Magacyada dheddigga ah

Iyaguna waxay wadar ku noqdaan dhammaadka oo laga raaciyo *-o*
(wadartu waxay noqotaa lab, qodobkooduna waa *-ha*):

| Keli | Wadar | Faallo |
| --- | --- | --- |
| kab(ta) | kabo(ha) | |
| dheg(ta) | dhego(ha) | |
| far(ta) | faro(ha) | |
| habar(ta) | habro(ha) | shaqalka labaad waa luntaa |
| gacan(ta) | gacmo(ha) | shaqalka labaad waa luntaa |
| nirig(ta) | nirgo(ha) | shaqalka labaad waa luntaa |
| cirib(ta) | cirbo(ha) | shaqalka labaad waa luntaa |
| mindi(da) | mindiyo(ha) | -y- ayaa la dhex dhigaa |
| tummaati(da) | tummaatiyo(ha) | -y- ayaa la dhex dhigaa |
| ri'(da) | riyo(ha) | -y- ayaa la dhex dhigaa |

Sida magacyada labka ah, kuwa ku dhammaada *-i* waxaa khasab ah in
*-y-* laga hormariyo *-o* wadareedda; dhismaha
shibbane+shaqal+shibbane+shaqal+shibbane wuxuu keenaa in la lumiyo
shaqalka labaad.

| --- | --- |

| hooyo(da) | hooyooyin(ka) |
| waddo(da) | waddooyin(ka) |
