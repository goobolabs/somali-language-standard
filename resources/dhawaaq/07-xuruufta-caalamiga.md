# Xuruufta caalamiga ah

Kaabadani waxay soo koobayaan xuruufta caalamiga ah (International
Phonetic Alphabet — IPA) iyo eray-bixinta codaynta ee cutubkanu
isticmaalo. Shaxannada sawirka ah ee buugga asalka ah lama soo
celin; tusayaasha hoose waxay tilmaamayaan mawduucyada cutubyada
kan ku xiga.

## IPA — alifbeetada caalamiga ah

Cutubkanu wuxuu isticmaalaa shaxanka IPA ee caadiga ah. Shibbanayaasha
waxa lagu kala saaraa meelaha jeojinta (bilabial, labiodental,
dental, alveolar, post-alveolar, retroflex, palatal, velar, uvular,
pharyngeal, glottal) iyo habka jeojinta (plosive, nasal, trill,
tap/flap, fricative, lateral fricative, approximant, lateral
approximant).

Shaqaallada waxa lagu kala saaraa dusha carrabka (close, near-close,
close-mid, mid, open-mid, near-open, open) iyo gadaal/hore (front,
central, back).

## Eray-bixin codayneed

### Meelaha jeojinta iyo moqorrada

| Eray | Sharax |
| --- | --- |
| **Meel** (point of articulation) | Meesha dhawaaqsameeyuhu taabto marka cod samaysmayo |
| **Moqorka afka** (oral cavity) | Rugta carrabka iyo ilkaha; waxa u dhexeeya cagagida iyo debnaha |
| **Moqorka dhuunta** (pharyngeal cavity) | Jidka u dhexeeya cidhibta iyo qalaanqulshaha; waxa ka samaysma /ħ/, /ʕ/, iyo /q/ |
| **Moqorka sanka** (nasal cavity) | Marin bannaan oo sanka ku yaal; /m/ iyo /n/ ayaa neefta ka baxdaa |
| **Moqorrada reenka** (resonating cavities) | Marka codadku ku soo dhacaan moqorrada, reenka durbaanka ayaa bilaabma |

### Noocyada codadka

| Eray | Sharax |
| --- | --- |
| **Hakadayaasha** (stops/plosives) | Codad sanaysma marka dhawaaqsameeye iyo neel is qabsadaan; sida /b/, /t/, /d/, /k/, /g/ |
| **Codlaawe** (voiceless) | Cod aan lahayn gariirka seedaha sanduuqa codka |
| **Codle** (voiced) | Cod leh gariirka seedaha sanduuqa codka marka ay xidhan yihiin |
| **Ma xoogaysan** (unaspirated) | Cod aan lahayn sanqadh xoog leh iyo neef marka uu ka soo baxo afka; sida /b/, /d/, /d/ ee hakadayaasha |
| **Koobishmaha** (lip position) | Meelaha iyo siyaabaha dhaqdhaqaaqa debnaha; marka labada debnood is qabsadaan waxa la yidhaahdaa cod bilabial |

### Shaqaallada

| Eray | Sharax |
| --- | --- |
| **Midab** (color) | Dabeecadda sumadda ugu nuhinsan ee lagu kala sooco shaqaallada |
| **Hore** (front) | Sumad ay shaqaalladu leeyihiin marka carrabku hore u kaco; sida /i/, /i:/, /e/, /e:/, /a/, /a:/ |
| **Hoose** (low) | Magac guud ee shaqaallada sanaysma marka labada daan aad u kala durugsan yihiin; sida /a/ iyo /a:/ |
| **Horaysiinta shaqaallada lammaan** (fronting of diphthongs) | Habka shaqaallada lammaan ee ka dambe ay tahay shaqal hore; sida /ai/, /ei/, /oi/ |

### Isbeddellada codka

| Eray | Sharax |
| --- | --- |
| **Isu ekaysiin** (assimilation) | Marka laba cod isu dhowaadaan oo mid uu isu ekaysiiyo midka kale |
| **Kala dhaadh** (dissimilation) | Marka kala duwanaanta laba cod ka badan tahay isu ekaantooda; sida /a/ iyo /x/, ama /t/ iyo /s/ |

### Codadka sare

| Eray | Sharax |
| --- | --- |
| **Kicin hoose** (low pitch) | Ku dhawaaqid hoose oo ku dheehan codadka taxan; /4/ |
| **Kicin caadi** (normal pitch) | Ku dhawaaqidda caadiga ah ee aan xanshashaq, dhawaaq dheer, iyo qaylo lahayn; /3/ |
| **Kicin sare** (mid pitch) | Marka dhawaaqa sare loo qaado si bayaan lagu maqlo; /2/ |
| **Kicin yaab** (high pitch) | Ku dhawaaqidda yaab ee qaylo dheer muujisa; /1/ |
| **Kicin hoosudhicid** (falling pitch) | Marka hoose loo soo dhigayo dhihid saraysay |
| **Kicin korukicid** (rising pitch) | Marka sare loo qaado dhihid hoosaysay |

### Hadalka

| Eray | Sharax |
| --- | --- |
| **Hadalka** (speech) | Shayga keli ah ee bani'aadamku kaga duwan yahay xayawaanka; waa hawo ama neef sabaynaysa oo qabqabsanta fikradaha |

## Xiriirka IPA iyo qoraalka Soomaaliga

Xuruufta qoraalka caadiga ah ee Af Soomaaliga waxay u dhigmaan
xuruufta IPA sida ishu tilmaanto: /c/ = /ʤ/, /x/ = /ħ/, /q/ = /q/,
iyo wixii la mid ah. Labaduba waxay tilmaamaan dhismaha hadalkeenna,
laakiin IPA waa qeexitaan codayneed halka qoraalka caadiga uu yahay
hab qoraal oo bulshada loo dejiyay. Astaanta xarafka SLS waxa laga
helayaa [`naxwe/01-ereyada.md`](../naxwe/01-ereyada.md) iyo
[`spec/orthography/0001-alphabet.md`](../../spec/orthography/0001-alphabet.md).
