# Magacyada — cayn, tirada, iyo wadar

Shaxda tixraaca ee **caynta** (lab/dheddig), **tirada** (keli/wadar), iyo
**qaababka wadareed**. Faahfaahinta barashada waxay ku taal
[`naxwe/02-sarfaha-magacyada.md`](../naxwe/02-sarfaha-magacyada.md).

**Ilaha:** *Barashada Naxwaha Af Soomaaliga* (Puglielli & Mansuur, 1998) —
S-003, cutub 2.

## Caynta iyo waafaqidda

| Cayn | Qodob (tusaale) | Magacuyaal (3aad) | Falka (tusaale) |
| --- | --- | --- | --- |
| Lab | -ku / -gu | buu (uu) | … yahay |
| Dheddig | -tu / -du | bay (ay) | … tahay |

Magacyada noolaha: caynta waxay ku xiran tahay jinsiga. Magacyada aan
noolayn: caynta waxaa laga ogaadaa waafaqidda curiyeyaasha weerta.

## Isbeddelka caynta marka wadar la sameeyo (gender polarity)

| Keli | Wadar | Isbeddel |
| --- | --- | --- |
| Lab → dheddig | *inanka* → *inamada* | Haa |
| Dheddig → lab | *naagta* → *naagaha* | Haa |
| Lab → lab | *miiska* → *miisaska* | Ma jiro (hal-alanle lab) |

## Aqoonsiga caynta (codkac)

| Tilmaam | Lab | Dheddig |
| --- | --- | --- |
| Codkac | kan ka horreeya shaqalka ugu dambeeya | shaqalka ugu dambeeya |
| Hal-alanle | cod culus | cod fudud |
| Dhammaad | -e | -o |

## Kooxaha wadareed — magacyada labka ah

| Koox | Habka | Tusaale keli → wadar |
| --- | --- | --- |
| L1 | Laballaab + -a | *buug* → *buugag* |
| L2a | -o (shibbane laballaab) | *doofaar* → *doofaarro* |
| L2b | -yo (dhex -y-) | *magac* → *magacyo* |
| L2c | -o (salka -y) | *gabay* → *gabayo* |
| L2d | luminta shaqalka 2aad + -o | *jilib* → *jilbo* |
| L3 | -yaal (salka -e) | *tuke* → *tukayaal* |
| L4 | -aan | *dhagax* → *dhagxaan* |
| L5 | qaab carbeed | *macallin* → *macallimiin* |
| L6 | durkidda codkaca | *awr* → *awr* (→ dheddig wadar) |

## Kooxaha wadareed — magacyada dheddigga ah

| Habka | Tusaale keli → wadar |
| --- | --- |
| -o (→ lab wadar) | *kab* → *kabo* |
| luminta shaqalka 2aad + -o | *gacan* → *gacmo* |
| -y- + -o | *mindi* → *mindiyo* |
| -oyin (salka -o) | *hooyo* → *hooyooyin* |

## Magacyada aan wadar yeelan

| Nooc | Tusaale |
| --- | --- |
| Ma-tirsame | *sonkor*, *biyo*, *caano* |
| Urur | *dad*, *geel*, *carruur* |
| Cillanaad (badanaa) | *run*, *jacayl*, *murugo* |

## Qodobbada iyo tilmaamayaasha

| Nooc | Tusaale |
| --- | --- |
| Qodob keli | *ninka*, *naagta*, *buugga* |
| Tilmaame | *ninkan*, *naagtaas*, *buuggaas* |

Qodobku wuxuu muujiyaa caynta magaca uu raaco.
