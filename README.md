# Somali Language Standard (SLS)

The open, machine-readable standard for the Somali language — grammar, orthography, terminology, translation guidance, style guides, and AI/benchmark resources, designed for use by AI models, RAG systems, translation and grammar tools, and NLP research.

See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the full architecture and implementation plan.

**Status:** Pre-implementation design (v0.1 planning).
